# Маршрут (Route Planner)

Адаптивный веб-планировщик путешествия: обложка поездки, выбор темпа, маршрут по дням, бюджет, бронирования и чек-лист подготовки. Работает полностью офлайн — без сборки, внешних библиотек и сети: достаточно открыть `app/index.html` в браузере.

Учебный проект с нуля: от брифа до критериев готовности и acceptance-тестов (см. `docs/technical-specification.md` и `references/design-brief.md`).

## Возможности

### Обложка поездки
- название поездки, даты, количество дней, обратный отсчёт;
- декоративная линия маршрута с точками (инлайн-SVG и CSS-градиенты, без внешних изображений).

### Темп путешествия
Переключатель «Спокойно» / «Насыщенно» изменяет:
- количество событий в выбранном дне;
- примерную стоимость дня;
- текстовую подсказку;
- общий прогноз расходов.

### Маршрут по дням
Выбор дня показывает город, дату, время, название события, категорию, стоимость и статус бронирования.

### Бюджет
- общий бюджет путешествия (180 000 ₽);
- запланированную сумму и остаток;
- прогресс-бар и категории расходов.

### Бронирования
Карточки: перелёт, отель, поезд, экскурсия. Неподтверждённое бронирование подтверждается кнопкой — статус меняется, появляется уведомление.

### Чек-лист подготовки
Категории: документы, деньги, вещи, здоровье. Отметки сохраняются в `localStorage`; есть кнопка «Сбросить учебные данные».

### Мобильный режим «Сегодня»
На узком экране акцент на текущем дне, ближайшем событии, месте, времени, статусе бронирования и следующей задаче. Компактная нижняя навигация: «Сегодня», «Маршрут», «Бюджет», «Подготовка».

### Состояния интерфейса
`loading` (скелетоны), `error` (сообщение и «Повторить»), `empty` (день без событий), `success` — плюс сворачиваемая панель «Демо состояний» для проверки.

## Технологии

| Компонент | Технология |
|---|---|
| Языки | HTML, CSS, JavaScript |
| Сборка | не требуется (без npm) |
| Зависимости | нет (без внешних библиотек и CDN) |
| Хранение | `localStorage` |
| Тесты | `pytest` (acceptance-тесты) |

## Установка и запуск

Приложение статическое — откройте `app/index.html` в браузере. При желании можно поднять локальный сервер:

```bash
python -m http.server 8080 --directory app
# затем откройте http://localhost:8080
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -v
```

Acceptance-тесты проверяют критерии готовности брифа (`tests/test_acceptance.py`, ветка `feature/acceptance-tests`). Шаблон CI: `docs/ci.yml.example`.

## Разработка (git-flow)

- `main` — релизная ветка;
- `develop` — интеграционная ветка;
- `feature/*` — ветки функций (объединяются через pull request).

## Ограничения

- Демонстрационные данные (поездка «Лиссабон и океан», 12–18 сентября).
- Хранение на уровне браузера (`localStorage`): данные не покидают устройство.
- Строго по брифу: без сети, без платных сервисов.
