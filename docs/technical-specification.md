# Техническое задание: планировщик путешествия «Маршрут»

Учебный проект из курса: статическое адаптивное веб-приложение для подготовки к путешествию. Все даты, суммы и бронирования являются демонстрационными.

## Источник

Проектный бриф — `references/design-brief.md`. Визуальный ориентир — `references/visual-reference.png` (не включается в приложение).

## Демонстрационная поездка

- Название: «Лиссабон и океан».
- Даты: 12–18 сентября 2026 года.
- Продолжительность: 7 дней.
- Маршрут: Лиссабон → Кашкайш → Синтра → Эрисейра → океан → Лиссабон.
- Общий бюджет: 180 000 ₽.

## Функциональные требования (FR)

### FR-01. Обложка поездки

Обложка отображает название поездки, даты (в формате «12 сентября–18 сентября»), количество дней, обратный отсчёт до отъезда и декоративную линию маршрута с точками городов. Обратный отсчёт принимает три состояния: «До отъезда осталось N дн/дня/дней», «Поехали!», «Путешествие завершено». Оформление обложки выполняется только средствами CSS-градиентов, простых фигур и встроенного SVG — без внешних изображений.

### FR-02. Темп путешествия

На странице «Маршрут» есть переключатель темпа с двумя вариантами: «Спокойно» (calm) и «Насыщенно» (intense). При переключении изменяются:

- набор событий выбранного дня;
- примерная стоимость дня;
- текстовая подсказка;
- общий прогноз расходов.

Выбранный темп сохраняется в `localStorage` и восстанавливается после перезагрузки.

### FR-03. Маршрут по дням

Пользователь выбирает день из табов (День 1 … День 7) и видит для него: город, дату, список событий. Каждое событие содержит время, название, категорию, стоимость и, при наличии, статус связанного бронирования («Подтверждено» / «Ожидание»). Переключение дня обновляет маршрут без перезагрузки страницы.

### FR-04. Бюджет

Блок бюджета отображает: общий бюджет (180 000 ₽), запланированную сумму, остаток, круговой прогресс использования и распределение по категориям (Транспорт, Жильё, Экскурсии, Еда, Активность). Цвет остатка зависит от значений: красный при перерасходе, жёлтый при остатке менее 10 %, зелёный в обычном случае.

### FR-05. Бронирования

Секция «Бронирования» показывает карточки: перелёт, отель, поезд, экскурсия. Для каждого — тип, название, детали, стоимость и статус. Для неподтверждённого бронирования отображается кнопка «Подтвердить»; после нажатия статус меняется на «Подтверждено» и появляется уведомление-тост.

### FR-06. Чек-лист подготовки

Чек-лист содержит категории «документы», «деньги», «вещи», «здоровье» с фильтрацией по вкладкам. Отметки сохраняются в `localStorage` и восстанавливаются после перезагрузки. Есть кнопка «Сбросить учебные данные», возвращающая бронирования, чек-лист и темп к исходному состоянию.

### FR-07. Мобильный режим «Сегодня»

На узком экране главный акцент переносится на вид «Сегодня»: текущий день, ближайшее событие (время, место, статус бронирования), ближайшее неподтверждённое бронирование и следующая задача из чек-листа. Добавлена компактная нижняя навигация: «Сегодня», «Маршрут», «Бюджет», «Подготовка».

### FR-08. Состояния интерфейса

Реализованы четырье состояния интерфейса:

- `loading` — карточки-скелетоны при первичной загрузке;
- `error` — сообщение об ошибке и кнопка «Повторить»;
- `empty` — день без событий с кнопками «Выбрать следующий день» и «Переключить темп»;
- `success` — обычное рабочее состояние.

Для проверки предусмотрена сворачиваемая панель «Демо состояний» с кнопками переключения состояний.

### FR-09. Адаптивность

Поддерживаются контрольные ширины: 1440 px (двухколоночная версия), 768 px (планшет), 390 px (мобильный режим «Сегодня»). Недопустимы горизонтальная прокрутка, наложение элементов и слишком мелкий текст.

### FR-10. Технические ограничения

Приложение использует только HTML, CSS и JavaScript (vanilla). Запрещены фреймворки, npm/сборщики, внешние библиотеки и CDN, базы данных, авторизация, внешние API и загрузка данных из интернета. Структура: `app/index.html`, `app/styles.css`, `app/app.js`. Приложение работает после обычного открытия `index.html` в браузере.

## Критерии приёмки (AC)

- **AC-01.** Файлы `app/index.html`, `app/styles.css`, `app/app.js` существуют.
- **AC-02.** В `app.js` определён объект `TRIP` с названием «Лиссабон и океан», датами 12–18 сентября 2026 и бюджетом 180 000 ₽.
- **AC-03.** Маршрут состоит из шести точек: Лиссабон → Кашкайш → Синтра → Эрисейра → Океан → Лиссабон.
- **AC-04.** Массив `DAYS_DATA` содержит ровно 7 дней, у каждого есть массивы событий для темпов `calm` и `intense`.
- **AC-05.** Переключение темпа меняет состав событий дня (у дня 1 набор `intense` отличается от `calm` и больше по количеству).
- **AC-06.** `BOOKINGS_DEFAULT` содержит 4 бронирования (перелёт, отель, поезд, экскурсия): два со статусом `confirmed` и два со статусом `pending`.
- **AC-07.** `CHECKLIST_DEFAULT` покрывает категории «документы», «деньги», «вещи», «здоровье» и содержит не менее 10 пунктов.
- **AC-08.** Для хранения используются ключи `localStorage`: `route_bookings`, `route_checklist`, `route_pace`.
- **AC-09.** В `index.html` присутствуют элементы: `#day-tabs`, `#day-info`, `#day-events`, `#budget-progress`, `#bookings-list`, `#checklist-items`, `#toast`, `#demo-panel`.
- **AC-10.** Для неподтверждённого бронирования в разметке и JS предусмотрена кнопка «Подтвердить» (`data-action="confirm"`), после подтверждения отображается тост.
- **AC-11.** Приложение обрабатывает состояния `loading`, `error`, `empty`, `success` (элементы `#app-loader`, `#app-error`, `#app-empty` и обработчик `onRetry`).
- **AC-12.** Реализованы функции `onReset`, `resetAllData` и «Сбросить учебные данные».
- **AC-13.** Мобильный режим: в `index.html` есть нижняя навигация `#bottom-nav` с четырьмя видами: «Сегодня», «Маршрут», «Бюджет», «Подготовка».
- **AC-14.** `app.js` компилируется без ошибок (`node --check app/app.js`).
- **AC-15.** В коде приложения нет внешних сетевых обращений: отсутствуют загрузка внешних ресурсов, CDN и API-вызовы (допускается только SVG-пространство имён).
- **AC-16.** В `styles.css` есть media-запросы для планшетной (768 px) и мобильной (не шире 600 px) компоновки и правило `prefers-reduced-motion`.
